# Emergency Medicine & Blood Finder

A simple web application designed to help people quickly find nearby hospitals, blood banks, and pharmacies during medical emergencies.

## Features

- 🏥 Find nearby hospitals
- 🩸 Find blood banks
- 💊 Find pharmacies
- 🚨 Post and view blood requests
- 🪪 Medical ID for important information
- 👥 Blood donor and supplier contacts
- 📍 Location-based search

## Technologies

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap

## How to Use

Open `index.html` in a web browser and allow location access to explore nearby medical services.

## Purpose

The goal of this project is to make essential medical resources easier to find and help people access the right information quickly during emergencies.
